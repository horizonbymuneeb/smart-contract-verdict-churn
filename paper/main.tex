\section*{Data and code availability}\label{sec:repro}
All contracts come from public repositories at pinned commits (SmartBugs-curated \texttt{\seqsplit{230e649123477eff332742a59a1c7cc6dc286cab}}; SWC Registry \texttt{\seqsplit{1b6227074ecd180b374e4844153afdda0332f979}}). All local models are public GGUF files; their SHA-256 hashes are listed in \ref{app:hashes}. The dataset builder, the resume-safe runners, the shared verdict parser, the analysis scripts, every raw model output (one JSON line per contract and run, including the raw text) and the table generator used for this manuscript are publicly available at \url{https://github.com/horizonbymuneeb/smart-contract-verdict-churn} (release v1, MIT licence) and archived together with this preprint on Zenodo (\url{https://doi.org/10.5281/zenodo.23241640}). The external API arm used a closed commercial aggregator whose backends cannot be pinned; its raw responses, including returned model names, finish reasons, latencies and token counts, are released with the same package, but the calls themselves cannot be guaranteed to be reproducible.
